# Dotfiles

My OS X / Ubuntu dotfiles, based on the [dotfiles of Ben Alman]("https://github.com/cowboy/dotfiles/").

The `source/` directory holds small shell snippets that are sourced by both
Bash and Zsh. Login shells source `link/.bashrc` or `link/.zshenv`, which in
turn load these shared snippets and any shell–specific customisation.
